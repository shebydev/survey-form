# Customer Satisfaction Survey Form

A simple web-based customer feedback form built with HTML. This form collects customer information, satisfaction levels, commonly used features, and additional comments to help businesses improve their products and services.

## Overview

This project is a static HTML page that presents a survey to users. It is designed to gather feedback on customer experience and service quality in a clear and user-friendly format.

## Features

- Contact information section
  - Full name
  - Email address
  - Age range
- Service satisfaction rating
  - Very Satisfied
  - Neutral
  - Unsatisfied
- Feature usage selection
  - Customer Support
  - Online Web Portal
  - Mobile Application
  - Billing & Invoicing
- Additional comments section for suggestions or issues
- Submit button to send the survey response
